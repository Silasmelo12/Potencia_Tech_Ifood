# Potencia Tech powered by iFood: Java Beginners

Exercicios desenvolvidos durante a trilha introdutoria de Java do programa Potencia Tech powered by iFood.

## Conteudos praticados

- Sintaxe, tipos, metodos e parametros
- Sobrecarga e estruturas de controle
- Exercicios com calculadora, mensagens, emprestimos e areas geometricas

Os exercicios estao separados por modulo e podem ser executados individualmente pelas respectivas classes `Main`.

> Repositorio de formacao, mantido como evidencia da base tecnica e da evolucao no ecossistema Java.
